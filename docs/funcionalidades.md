# Funcionalidades del Sistema

A continuación se presentan las funcionalidades previstas para el desarrollo del proyecto:

* **Registrar tareas:** Crear y almacenar nuevas tareas especificando título, descripción y fecha límite.
* **Consultar tareas:** Listar y visualizar todas las actividades registradas con su estado actual.
* **Modificar tareas:** Editar los detalles o fechas de tareas previamente guardadas.
* **Marcar tareas como terminadas:** Actualizar el estado de una tarea para indicar su cumplimiento.
* **Registrar notas:** Redactar y guardar anotaciones o recordatorios rápidos independientes de las tareas.
